# 미국 건설 프로토타입 (WW2 US · 턴제 카드 국가 건설)

Stacklands 식 **카드 스택 조작** + 상점에서 카드를 사서 국가를 키우는 **4X 진행**을 합친
턴제 프로토타입입니다. 이번 단계의 목표는 핵심 플레이 루프 확인이라 **전투 · 승리 조건 ·
세이브는 아직 없습니다.**

## 실행 방법

`index.html` 을 더블클릭하면 끝입니다. 서버도, 설치도, 빌드도 필요 없습니다.
(모든 데이터를 평범한 `<script src>` 로 불러오기 때문에 `file://` 에서 그대로 돌아갑니다.)

## 조작

| 행동 | 방법 |
|---|---|
| 카드 옮기기 | 카드를 잡고 원하는 곳에 놓기 |
| 카드 쌓기 | 카드를 다른 카드 **위에 겹쳐서** 놓기 (집은 카드 위에 얹혀 있던 카드들도 따라옵니다) |
| 카드 사기 | 상점 카드 클릭 (황금/식량은 보드 위 카드 총합에서 자동 차감) |
| 카드 정보 | 카드에 마우스를 올리면 좌하단에 설명·레시피 표시 |
| 턴 넘기기 | 우상단 **턴 종료** 버튼 |

이번 턴 종료 시 **실제로 발동할** 건물은 노란 테두리와 결과 배지(`▶ 총기 ×2`)로 표시됩니다.

## 턴 진행

1. **턴 시작** — `baseProductionResource` 가 있는 카드(자원지, 백악관)가 조건 없이 자동 생산
2. **플레이어 턴** — 구매 · 드래그 · 스택 (이 시점에는 빈 상점 칸이 채워지지 않음)
3. **턴 종료** — 건물별 레시피 판정 → 재료 소모/결과 생성 → 빈 상점 칸 무작위 보충 → 턴 +1

레시피 판정 규칙:

- 재료는 **그 건물 카드 위에 실제로 스택되어 있어야** 조건이 성립합니다.
- 한 건물에서 `produceCard` 레시피 여러 개가 동시에 조건을 만족하면 `resultQty` 가 가장 큰
  것 **하나만** 발동합니다(같으면 엑셀에서 더 위에 있는 레시피).
- `modifyStat` 레시피는 이 경쟁과 무관하게 독립 판정되어 같은 턴에 함께 발동할 수 있습니다.
- 소모되는 것은 `Consumed=TRUE` 인 재료뿐입니다.

## 파일 구성

```
index.html          뼈대 + 스타일
cards-data.js       엑셀에서 변환된 카드/레시피 데이터  ← 자동 생성, 직접 고치지 마세요
game.js             게임 상태 · 턴 로직 · 레시피 엔진
render.js           화면 그리기 · 드래그 처리
card_recipe_table_v3.xlsx   원본 밸런스 시트 (여기를 고칩니다)
update-data.bat     엑셀 → cards-data.js 변환 실행
tools/convert_xlsx_to_js.ps1   실제 변환 스크립트
```

## 밸런스 수정하는 법

1. `card_recipe_table_v3.xlsx` 의 **'카드'** 또는 **'레시피'** 시트를 고치고 **저장 후 닫습니다.**
2. `update-data.bat` 을 더블클릭합니다. (`cards-data.js` 가 새로 만들어집니다)
3. 열려 있던 `index.html` 을 **F5** 로 새로고침합니다.

`game.js` 를 고칠 필요는 없습니다. 아래는 엑셀만 고쳐도 게임에 그대로 반영됩니다.

- 카드 추가/삭제, 이름·설명·가격·생산량·공격력·체력 변경
- 상점 등장 여부(`appearsInStartShop` / `appearsInLaterPool`), 시작 배치(`startsOnBoard`)
- 레시피의 재료·수량·소모 여부·결과물·수량 전부
- **화폐**(누군가의 `costResource` 로 쓰이는 자원)와 **상단바에 표시할 자원** 목록도
  데이터에서 자동으로 뽑아냅니다. 새 자원을 추가하면 상단바에 칸이 자동으로 생깁니다.
- 아이콘이 없는 새 카드는 종류별 기본 아이콘으로 그려집니다. 전용 아이콘을 주고 싶을 때만
  `game.js` 의 `CARD_ICONS` 에 한 줄 추가하면 됩니다.

### 변환 시 자동 검사

변환 스크립트가 흔한 실수를 잡아서 알려줍니다. 문제가 있으면 검은 창에 목록이 뜨고,
게임 화면 상단에도 빨간 배너로 표시됩니다 (게임은 그래도 실행됩니다).

- 존재하지 않는 카드 id 를 재료/결과물/생산물로 지정한 경우
- id 중복, 모르는 `type`, 모르는 `resultType`
- 가격은 있는데 `costAmount` 가 비었거나, 가격 없이 상점에 등장하도록 설정된 경우
- `appearsInStartShop=TRUE` 카드 수가 상점 5칸과 맞지 않는 경우

### 참고

- `update-data.bat` 은 PowerShell 로 xlsx 를 직접 읽습니다. 파이썬이나 다른 설치가 필요
  없습니다. 다만 **엑셀에서 파일을 연 채로 돌리면 실패**하니 저장 후 닫고 실행하세요.
- 상점 칸 수(5칸)와 보드 크기는 UI 규칙이라 엑셀이 아니라 `game.js` 상단 상수에 있습니다.
